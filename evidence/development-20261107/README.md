# November development evidence

This publication covers the rendering, terrain, mapping and capture work through the November 7, 2026 continuous-collection handoff. Recorded hardware results keep their original dates. Publishing these files does not run a new hardware trial or change the active Halo collection.

The [manifest](manifest.json) records each selected local source path, original SHA-256, published SHA-256 and byte count. Copies differ only where CRLF line endings were normalized to LF for Git. Raw scene bundles, datasets, RGB-D recordings, operator kits, compiled environments and large evidence archives remain outside GitHub. Archive receipts identify verified off-host copies without redistributing them. Paths inside historical reports identify the original deployment; they are not files supplied by this checkout.

Middleware import doubles allow capture ordering checks on a CPU-only machine; native Halo tooling, Linux process checks and real ROCm execution are skipped when unavailable. The deployed supervisor source remains unchanged. Publication additionally makes the ordering fixture's clock deterministic and bounds Windows review-page sharing retries; those edits have no new rendered-Halo acceptance claim.

The [project verification guide](../../docs/VERIFICATION.md) and [roadmap](../../docs/ROADMAP.md) describe remaining acceptance. The 10,000-image dataset, four-class export, human review, detector training, endurance and autonomous navigation are not declared complete by this publication.
